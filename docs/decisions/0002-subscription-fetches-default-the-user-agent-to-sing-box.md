# Subscription fetches default the User-Agent to `sing-box/<installed version>`

uclient-fetch's own UA is anonymous tooling noise to subscription providers, which increasingly gate the reply — or pick its format — on a recognisable client UA. Identifying as the engine Prism actually feeds (`sing-box/1.12`, version taken live from the installed binary) is the honest choice and steers UA-sniffing providers toward the sing-box or generic URI-list flavour rather than HTML or a block page. The version is truncated to major.minor: field testing showed at least one provider (SSRDog) rejects the UA when the full patch version (`sing-box/1.12.4`) is appended, presumably matching against known client-version patterns. The version comes from `singbox_version()`, factored out of `get_status`'s inline tmpfs-cached lookup (`/var/etc/prism/.singbox-version`) so a multi-subscription sync doesn't fork sing-box per sub; when the binary is missing the UA falls back to bare `sing-box`. An explicit per-subscription `user_agent` still overrides, and the UI placeholder now names the default instead of "Leave blank for default".
